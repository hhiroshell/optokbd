## 底蓋とコントローラー収納部（`bay.py`）

### 留め方

- **底蓋を底蓋の面に垂直にまっすぐ押し込み、四隅を M2 × 6 の六角穴付きボルトで留める**。ボトムケースのボスに横から差し込んだ M2 ナットに締める
- 押し込む向きは奥へ 6° 傾いているので、押し込む途中の部品は閉じた位置より奥の壁から離れている
- やめた方式: ラッチ（印刷で精度が出ない）、手前のツメを軸に回して閉める（ツメが抜けかけた状態で回り始め、USB-C が奥の壁に当たった）、
  奥の中央 1 本のネジ（奥の角が浮いた）

### 寸法（平面の座標はプレート DXF、z はボトムケース、w は底蓋の外面から垂直に）

- 底蓋: x 25.63〜106.23、手前の端 y −34.5（底蓋に垂直な面）、奥の端は奥の外形から 5.8 内側の円弧（鉛直）。厚さ 1.6
  - 左端は左のボスの位置で決まる（電池の左横にボスを置くため、以前より 1.5 mm 広げた）
- 四隅のネジ: 底蓋の各辺から 3.2 内側。FRAME の (x, v) は (28.83, −31.49)、(28.83, −8.03)、(103.03, −31.49)、(103.03, −7.83)
  - 底蓋: 座ぐり Ø4.4 × 深さ 2.0、通し穴 Ø2.4。角の台（厚肉）は底蓋の内面から 1.6（w 3.2）で、平面形はボスと同じ（円 + 隣り合う 2 辺までの四角）
  - ボトムケースのボス: 平面形は円（r 3.2）+ 隣り合う 2 つの壁へ入り込む四角。w 3.2（台の上面に当たる）から床の上面（z 14.5）まで、底蓋に垂直。
    ナットの溝は w 5.4〜7.2、収納部の内側へ口が開く（左のボスは右、右のボスは左）。通し穴は w 8.4 まで。いちばん低い手前のボスの上端は w 8.96
- リブ: 厚さ 1.2、底蓋の内面から 4.0、上端の角を 0.4 面取り。左右、手前（電池側）、奥の辺に沿う
  - ボスのまわりは「ボスの平面形を 0.3 広げ、台の上面から上へ 45° で広がる立体」（`boss_flare`）で削る。リブと電池の枠は 45° の斜面で台につながる
  - 奥のリブは、基板の横幅 + 0.5 の範囲だけ w 3.0（基板の下面の 0.1 下）まで低くする（基板の縁、XIAO、USB-C に当たらないように）
- 電池: 実測 31 × 21 × 6。x 32.53〜63.53、手前の端 y −30.5。枠（厚さ 1.0、高さ 2.0、すき間 0.4）は左右と手前のリブとつながる
  - 基板側の辺の奥の角から 8 mm を開ける（リード線の通り道）、奥の辺の中央に幅 6 mm の切り欠き（スパッジャー用）
- 収納部: 天井なし（床を抜いてボトムケースの内側の空間とつなげる。ボトムケースは傾いた底面を下にして印刷するので、天井が斜めの張り出しになって
  きれいに印刷できなかった）。棚もなし。収納部の壁は、左右は x 一定の面、手前は底蓋に垂直な面、奥は鉛直な円弧
- USB-C: 基板の奥の端は奥の外形から 7.5（`BOARD_BACK`）。USB-C の口と奥の壁のすき間は 0.40（閉じた位置。あと 0.2 寄せられる）。
  奥の壁に USB-C の大きさ + 0.3 のプラグの穴、面取りの斜面に 13 × 7.5 のくぼみ（底は USB-C の口から 2.0 奥、`PLUG_GAP`）
- コードの中の確認（assert）: 基板・XIAO・USB-C と奥の壁のすき間 ≥ 0.2、ネジの通し穴がボスの中に収まる、電池が床の上面より下、右のリブと基板のすき間
- 出力: `lid-l`、`screw-test-l`（右手前の角）、`bay-fit-test-l`（底蓋のまわりのボトムケース）、`controller-board-l.dxf`（基板の外形と穴）

## コントローラー基板（左右共通）

### 外形と穴（`bay.py` で作る）

- 基板の座標: 原点は奥の辺の直線部分（XIAO の幅）の中央、y は奥が正。38 × 29、厚さ 1.0
- 左右対称。奥の肩は円弧、四隅にボスを逃がす切り欠き（左手のケースでは右の 2 つ、右手では左の 2 つを使う）、角はすべて R1.0（`BOARD_CORNER_R`）
- 取り付け穴 M2: (±12, −7)、(±11, −26)。底蓋の台座（Ø5、高さ 1.5、下穴 Ø1.6 × 2.4）に M2 × 3 のタッピングネジで留める（M2 × 4 は長すぎる）

### KiCad（`pcbs/controller/controller.kicad_pcb`）

- 基板の原点を KiCad の (100, 90) に置き、グリッドと補助原点もそこにした（KiCad の座標表示 = 基板の座標、y の符号だけ逆）
- Edge.Cuts は `bay.board_outline_segments()`（直線と 3 点の円弧）を pcbnew で書き込んだもの。外形を変えたら同じように入れ直す:

  ```python
  # bay.board_outline_segments() を JSON にして、システムの python3 で
  P = lambda x, y: pcbnew.VECTOR2I(pcbnew.FromMM(100 + x), pcbnew.FromMM(90 - y))
  # 直線: SHAPE_T_SEGMENT で SetStart/SetEnd、円弧: SHAPE_T_ARC で SetArcGeometry(始点, 中点, 終点)。層は Edge_Cuts、幅 0.05
  ```

- 部品の配置（基板の座標、コートヤードの範囲）

  | 部品 | 位置 |
  |---|---|
  | U1 XIAO | USB-C の端を奥の辺の直線部分に、XIAO の中心を x 0 に（フットプリントの原点は (0.045, −10.55)） |
  | J1 JST SM11B-SRSS-TB（横型） | 原点 (0, −24.375)、差し込み口は手前。左右の中央（マトリクス側 J1 との左右のずれが左右の手で同じ 18.5） |
  | J2 / J3 JST S2B-PH-K（横型、電池） | x −18〜−11 / +11〜+18、y −9.6〜−18.3、差し込み口は手前。左手は J2、右手は J3 を使う |
  | H1〜H4 | 取り付け穴（`MountingHole_2.2mm_M2`、回路図に記号のない基板だけの部品。「回路図から基板を更新」で消さないよう注意） |

- DRC で残るのは、XIAO のフットプリントのシルク（パッドや基板の端にかかる）の警告と、未配線だけ
- 配線の方針（合意済み、まだ配線していない）:
  - 電源は B.Cu だけ: J2 / J3（スルーホール）から U1 の 19（VBAT）・20（GND、XIAO の裏の電池パッドへ通すスルーホール）へ、0.5 mm。
    J2 の GND は H1 の台座を手前側で避ける。J3 からは XIAO の下を通し、GND を奥側、VBAT を手前側にすると交差しない
  - 信号は F.Cu: D0〜D6 を XIAO の左、D7〜D10 を右から手前へ下ろして J1 へ。今の J1 のピン順（ピン 1 = D0 … 11 = D10）で交差なく引ける。
    いちばん狭いのは XIAO の手前の端と J1 の間（0.65 mm）。D0〜D3 などをビアで裏に回すのがよさそう
  - 避ける所: ネジ頭（表、穴の中心から r 2.5）、底蓋の台座（裏、r 3）、基板の縁から 0.3〜0.5。GND ベタはなしか、アンテナから離れた裏だけ
- ケーブル側の部品: J1 は SHR-11V-S(-B) + SSH-003T-P0.2（圧着済みケーブルを使う）。J2 / J3 は PHR-2

## ハマりどころ（前回のメモに追加）

- 時計回りの輪郭の面は法線が下を向くので、`extrude` が下へ伸びる。左右で輪郭を反転する形（ナットの溝）で起きた。`dir=(0, 0, 1)` で向きを固定する
- `extrude(face, amount, taper=-45)` は外へ広がる押し出し（45° の斜面）。円と四角を合わせた面（Sketch）でも作れる
- 2D の `fillet()` は Sketch を返すので `.faces()[0]` で Face にする
- 親指キーは傾いているので、反転したスイッチの角度は 180° ちょうどにならない（−185.5° など）。反転済みかはキー本来の角度との差で判定する
- `kicad-cli pcb export drill` の座標は y が上向き。`--drill-origin plot` で補助原点基準になる
- 基板（底蓋に平行）の縁は底蓋に垂直なので、高い所ほど平面で奥へずれる（基板の上面で約 0.43）。プレビュー用の基板もこの形で作っている
